## What is LocaleKit?

LocaleKit is a macOS app that takes the headache out of managing app translations. Whether you're building for iOS, Android, Flutter, or React Native, LocaleKit keeps all your localization files organized and up-to-date with powerful AI translation engines.

## Features

- **Multi-Platform Support** — Works with Xcode, Android Studio, Flutter, and React Native projects all in one place

- **AI-Powered Translation** — Choose your engine:
  - Apple Intelligence (free & private - runs on device)
  - DeepL (high-quality translations)
  - OpenAI (GPT-powered)

- **Workspace Management** — Organize multiple apps and projects cleanly

- **Batch Translation** — Translate entire languages at once, not string by string

- **Progress Tracking** — See exactly how complete each language is at a glance

- **Format Conversion** — Export between different localization formats seamlessly

---

## Supported Formats

| Platform | Formats |
|----------|---------|
| Xcode | `.xcstrings`, `.strings`, `.stringsdict`, `.xliff` |
| Android | `strings.xml`, `.properties` |
| Flutter | `.arb` |
| React Native | `.json` (standard, i18next, react-intl) |

## Installation

1. Download LocaleKit from [localekit.app](https://localekit.app)
2. Drag to your Applications folder
3. Launch and you're ready to go

**Requirements:** macOS 14.0 (Sonoma) or later

LocaleKit automatically checks for updates and keeps itself current via Sparkle.

## Quick Start

1. **Create a workspace** — Group your related projects together
2. **Import your localization files** — Drag & drop or use File > Import
3. **Add target languages** — Pick the languages you want to support
4. **Translate** — Use AI translation or enter translations manually
5. **Export** — Save back to your project in any supported format
